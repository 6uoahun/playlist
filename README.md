## GitHub Pages 배포 방법

1. GitHub에서 새 Repository를 만듭니다.
2. 이 폴더의 **파일 3개(index.html, .nojekyll, README.md)**를 Repository 최상위에 업로드합니다.
3. Repository의 **Settings → Pages**로 이동합니다.
4. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, Folder는 `/(root)`로 선택하고 **Save**를 누릅니다.
6. 잠시 후 생성된 GitHub Pages 주소로 접속합니다.

`index.html`이 Repository의 선택한 배포 폴더 최상위에 있어야 합니다.

## YouTube 관련

곡 정보에는 YouTube 링크가 포함되어 있으며, 임베드 플레이어에는 오류 상황에 대비한 YouTube 직접 보기 링크도 포함되어 있습니다.

브라우저에서 HTML 파일을 직접 여는 `file://` 방식 대신 GitHub Pages의 `https://` 주소에서 실행하는 것을 권장합니다.
